# 迷你地铁 · 粤港澳 2026

以真实经纬度 1:1 建模的粤港澳大湾区地铁经营游戏。用 Three.js 渲染 3D 地形，按《迷你地铁》的规则拖拽铺线、疏导客流。

## 运行

```bash
npm install
npm run dev      # 开发服务器 http://localhost:5173
npm run build    # 构建为单个 dist/index.html（约 1 MB）
npm run preview  # 预览构建产物
```

## 玩法

- 从车站拖到另一车站开通线路；拖端点站延伸，拖线路中段的 ⊕ 把手改道，把中间站拖离＝取消停靠
- 乘客带形状标记，只去与自己形状相同的车站；线路换乘由引擎自动寻路
- 多线交汇的车站自动升级为立体换乘枢纽（多层站台）
- 跨海段按盾构隧道计费，造价约为陆地的 4 倍
- 车站候车人数超容一段时间即运营中断；**只有已接入线网的车站会触发该判定**
- 随机事件：台风（全网限速）、春运（客流 ×2.2）、广交会（广州客流 ×3.2）

## 结构

```
src/
  App.tsx            HUD / 面板 / 标题界面（React + Tailwind）
  game/
    engine.ts        纯逻辑：线路、列车、乘客路由、经济、事件、平衡参数
    geo.ts           经纬度投影（等距圆柱）+ 陆地掩码（离屏 canvas）
    path.ts          三次 Hermite 样条线路中心线、沿线采样
    ribbon.ts        沿路径生成带状几何（宽度在顶点着色器展开）
    world.ts         场景：海洋、拉伸地块、城市建筑、列车实例化
    stationView.ts   车站与换乘枢纽的三维模型
    models.ts        程序化贴图与列车几何
    view.ts          相机控制、拾取、拖拽交互、2D 覆盖层
  data/
    gd.json          23 个地级市/特区边界（GeoLite 风格：id/name/polys）
    regions.ts       城市、站点真实经纬度、线路配色
```

共 23 个行政区、95 个站点，地图实际范围约 796 × 610 km。

## 调参

`src/game/engine.ts` 顶部的 `BAL` 集中了全部平衡参数（起步资金、站台容量、
客流生成速率、超容判定时长等），改完可直接用 Node 跑模拟回归，无需浏览器。
